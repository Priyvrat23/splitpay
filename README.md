# SplitPay

> Production-grade group expense splitter with AI-powered insights.
> Built to demonstrate end-to-end DevOps: Jenkins CI/CD · Docker · Kubernetes · Prometheus · Grafana

## Stack
- **Auth Service** — Node.js / Express
- **Expense Service** — Node.js / Express
- **Insights Service** — Python / FastAPI
- **Frontend** — Next.js 14
- **Orchestration** — Kubernetes (minikube)
- **CI/CD** — Jenkins
- **Monitoring** — Prometheus + Grafana + Alertmanager
